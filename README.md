# MelodyToMIDI browser tool catalog

Reusable, source-linked notes about the MelodyToMIDI browser converter.

Source pages:

- [MP3 to MIDI](https://melodytomidi.com/)
- [Audio to MIDI](https://melodytomidi.com/audio-to-midi/)
- [WAV to MIDI](https://melodytomidi.com/wav-to-midi/)
- [MP3 to MIDI Converter](https://melodytomidi.com/mp3-to-midi-converter/)
- [Change MP3 to MIDI](https://melodytomidi.com/change-mp3-to-midi/)

The pages state that processing happens in the visitor's browser and files are not uploaded to a server. This catalog transcribes published page statements; it is not a benchmark.

## Files

- `tool-capabilities.csv` records the shared controls and output behavior.
- `page-index.csv` lists the public tool pages and their target phrases.
